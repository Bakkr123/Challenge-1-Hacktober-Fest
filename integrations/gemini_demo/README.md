# Hosted Gemma demo

This is an explicit hosted evaluation path for synthetic text or images. Set
`GEMINI_API_KEY` in the ignored root `.env`, then run:

```bash
PYTHONPATH=backend .venv/bin/python integrations/gemini_demo/run.py
```

The model is `gemma-4-26b-a4b-it`. Never use this script with real survivor
reports or personal imagery.
